# Các bài toán trong Trí Tuệ Nhân Tạo

## Biểu diễn vấn đề trong không gian trạng thái

| Ký hiệu | Tên tiếng Anh | Ý nghĩa |
| :--- | :--- | :--- |
| T | Tập trạng thái (States) | Tập hợp tất cả trạng thái có thể có của bài toán |
| S | Trạng thái ban đầu (Start State) | Trạng thái xuất phát của bài toán |
| G | Trạng thái đích (Goal State) | Trạng thái cần đạt được |
| F | Tập phép toán (Operators/Functions) | Các phép toán có thể áp dụng để chuyển từ trạng thái này sang trạng thái khác |
